Features

  • Tasks: add, complete, edit, swipe to delete with undo, priority, due time, filters, progress bar
  • Calc: running tape, undo, copy, save result or full tape to a note
  • Notes: write under saved calculations, set a reminder (notification on phone, banner on web)
  • Everything saved on the device, works offline

Tech

  • Expo SDK (latest), React Native, TypeScript, Expo Router tabs
  • Zustand state layer with persistence (AsyncStorage)
  • Reanimated for layout, swipe and theme animations
  • Unit tests for the calculator engine and stores
  • Web build on Vercel, with the repo's history kept

Palette

Coral, violet, pink and lime on paper or ink. Bricolage Grotesque for type, JetBrains Mono for numbers. Thick outlines with offset shadows.
